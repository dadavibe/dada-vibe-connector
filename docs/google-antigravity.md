# Logic Pro & REAPER MCP with Google Antigravity

1. Install and open **Google Antigravity** on the Mac where Logic Pro or REAPER runs and finish its initial sign-in.
2. In Dada Vibe Connector, open **Connection**, find **Google Antigravity**, and click **Verify**. The connector registers locally and saves tool permissions for new Antigravity chats.
3. If Google Antigravity was already open, quit and reopen it. Always keep your session **local** on this Mac (never in a cloud environment).
4. Recommended models: **Gemini 4 Neon (Medium or High)** for full tracks and arrangements, or **Gemini 4 Hydrogen** for fast edits, mixing and saving usage limits.
5. Grant the requested macOS permissions and run the read-only check from the [README](../README.md#quick-start).

**Tip:** Switch message delivery in Antigravity to **Send immediately** if you want to steer the music live in real time while listening, or leave the default queue mode to stack follow-up instructions without interrupting the current step.

More: https://dadavibe.com/getting-started/
