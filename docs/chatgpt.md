# Logic Pro MCP with ChatGPT for Mac (Work, Codex)

1. Sign in to the ChatGPT desktop app on the Mac where Logic Pro runs and open **Work** or **Codex**. An ordinary chat, the web or the mobile app alone cannot operate your local Logic installation.
2. Choose the **local** environment, not a cloud environment, and select **@Dada Vibe Connector**.
3. In Dada Vibe Connector, choose **ChatGPT / Codex** and follow the setup. Restart the assistant if prompted and check that its MCP tools include Dada Vibe Connector.
4. With your confirmation, the connector can add an approval for its own tools in Codex. You can decline and manage approvals in Codex settings.
5. Grant the macOS permissions and run the read-only check from the [README](../README.md#quick-start).

More: https://dadavibe.com/getting-started/
