# Logic Pro MCP with VS Code and GitHub Copilot

1. Install VS Code with GitHub Copilot on the Mac where Logic Pro runs.
2. In Dada Vibe Connector, open **Connection** → **More clients** → **GitHub Copilot in VS Code** and follow the setup.
3. Use Copilot agent chat in VS Code and check that the Dada Vibe Connector tools are available.
4. Optional, for fewer approval prompts: Command Palette → **Chat: Manage Tool Approval** → turn off "Configure for this workspace only" → expand Dada Vibe Connector → "Run any tool without approval" → OK. Leave other sources unchanged.
5. Grant the macOS permissions and run the read-only check from the [README](../README.md#quick-start).

VS Code documentation on MCP servers: https://code.visualstudio.com/docs/copilot/customization/mcp-servers

More: https://dadavibe.com/getting-started/
