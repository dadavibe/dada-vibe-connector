# Logic Pro & REAPER MCP in VS Code (Codex, Claude Code)

1. Install Visual Studio Code on the Mac where Logic Pro or REAPER runs, along with the **Codex** extension (ChatGPT account) or **Claude Code** extension (Claude account).
2. In Dada Vibe Connector, open **Connection** → **Visual Studio Code** and click **Use this connector**.
3. Reopen VS Code if prompted and verify in your local Codex or Claude Code session that the **Dada Vibe Connector** MCP tools are loaded.
4. Grant the requested macOS permissions and run the read-only check from the [README](../README.md#quick-start).

VS Code documentation on MCP servers: https://code.visualstudio.com/docs/copilot/customization/mcp-servers

More: https://dadavibe.com/vscode-copilot-logic-pro/
