# Logic Pro MCP with VS Code and GitHub Copilot

1. Install VS Code with GitHub Copilot on the Mac where Logic Pro runs.
2. In Dada Vibe Connector, choose **VS Code** and follow the setup; it adds the local MCP server to your VS Code configuration.
3. In Copilot Chat (agent mode), check that the Dada Vibe Connector tools are available and enabled.
4. Grant the macOS permissions and run the read-only check from the [README](../README.md#quick-start).

VS Code documentation on MCP servers: https://code.visualstudio.com/docs/copilot/customization/mcp-servers

More: https://dadavibe.com/getting-started/
