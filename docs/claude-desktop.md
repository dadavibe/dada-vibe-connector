# Logic Pro MCP with Claude Desktop

1. Install Claude Desktop and sign in (a Free account works, with usage limits).
2. In Dada Vibe Connector, choose **Claude Desktop** and complete the connection setup. Restart Claude when prompted.
3. In Claude's settings, open the local MCP servers / extensions area and check that **Dada Vibe Connector** is connected and enabled.
4. When Claude asks to run a tool, choose "Allow once" or "Always allow" for that tool. With your explicit confirmation the connector can switch its own tools to "Always allow" for you.
5. Grant the macOS permissions and run the read-only check from the [README](../README.md#quick-start).

The connection uses Claude Desktop on the same Mac as Logic Pro, not the Claude website or mobile app. You can continue the same chat thread from your phone with Claude's remote features while the Mac does the work.

More: https://dadavibe.com/getting-started/
